# Stitch cover images · Work & Insights

76 cover images made with **Google Stitch**: 4 variants for each of the 12 Work case studies and 7 Insights articles. Each project has its own theme (palette, fonts and mood) based on what the project is about, so no two projects share a look.

- **Work** covers: 1600 × 1000 JPG (16:10), in `work/<slug>/`
- **Insights** covers: 1600 × 900 JPG (16:9), in `insights/<slug>/`
- Use them on the site as `/images/stitch/...` (full list at the end)
- Text is kept large and sparse so it stays readable as a thumbnail. The top-left corner is left clear for the category tag.

**How to choose:** reply with one letter per project, e.g. `careflow B, opshub D, …`. You can also fill in the *Pick* column below.
